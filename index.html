ขั้นตอนเปิดใช้ backend

  1. เปิด Google Sheet ที่เตรียมไว้ แล้วไปที่ Extensions > Apps Script
  2. นำไฟล์ apps-script/Code.gs ใน repo นี้ไปวางแทนโค้ดเดิม
  3. กด Deploy > New deployment > Web app
  4. ตั้ง Execute as: Me และ Who has access: Anyone with the link
  5. คัดลอก Web App URL มาใส่ในช่องด้านซ้าย แล้วกดทดสอบ Sync
